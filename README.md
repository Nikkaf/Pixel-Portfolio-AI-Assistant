# Pixel Portfolio AI Assistant

A conversational portfolio experience that helps visitors learn about Nikka Foroughi's UX and product design work through guided questions and pre-programmed answers.

## Live experience

[Open the Portfolio AI Assistant](https://portfolio-ai-assistant.nfi134.chatgpt.site)

## About the project

This single-page experience was created for Day 10 of the MDEI Intensive. It offers a more conversational way to explore my portfolio while preserving the visual identity of my pixel-inspired personal website.

Visitors can ask about:

- My target product and UX design roles
- My ICBC, Castofly, and Reablement projects
- My skills, experience, process, and measurable impact
- My fit for companies including EA, Meta, Google, and Amazon

The responses are pre-programmed using information from my resume and portfolio. This is a portfolio interface, not a generative AI chatbot.

## Key features

- Chat-style question and response flow
- Suggested questions for guided exploration
- Intent matching for natural variations in visitor questions
- Responsive desktop, tablet, and mobile layouts
- Accessible labels, visible focus states, and high-contrast UI
- Pixel-inspired styling aligned with [nikka.me](https://www.nikka.me)

## Selected design direction

The interface combines a minimal square-line system with Nikka's Teal Bird identity. VT323 is used selectively for display text, JetBrains Mono supports interface readability, and the palette uses deep navy, teal, coral, and neutral gray.

## Built with

- React and TypeScript
- CSS
- Vinext/Vite
- Cloudflare-compatible deployment tooling

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
